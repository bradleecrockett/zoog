# Zoog

Create a drawing of a Zoog character using P5JS and the 4 primitive shapes that we learned in class. Also, use at least 2 colors in your drawing. Your Zoog can be an animal, cartoon, alien, bug or any other character that you would like to create.

For help, you might want to watch the videos: 

- Shapes: https://youtu.be/c3TeLi6Ns1E?list=PLRqwX-V7Uu6Zy51Q-x9tMWIv9cueOFTFA 
- Colors: https://www.youtube.com/watch?v=riiJTF5-N7c&list=PLRqwX-V7Uu6Zy51Q-x9tMWIv9cueOFTFA&index=5&pp=iAQB
- P5JS Reference: https://p5js.org/reference 


## Rubric
| Requirement | Points |
| --- | --- |
| The Zoog must look like an animal, bug, or character. | 2 |
| The program must use at least 4 shapes total. | 4 |
| At least 3 unique shapes must be used. ellipse, rect, line, point etc. | 2 |
| You must use at least 3 colors. | 2 |  
| Total | 10 |

Want extra credit? Go above and beyond... Use the reference page above to learn about a shape or function that was not taught yet and incorporate it into your project.
